# environment-view: .NET 10 repro

A .NET 10.0.102 Blazor Web App (WebAssembly interactivity, prerendering on, as the template ships) showing why "show a test-data banner except in Production" had no single answer before `<EnvironmentView>`. `EnvRepro.Client/Banners/WasmBanner.razor` injects `IWebAssemblyHostEnvironment`; rendered on `/wasm-env` with `InteractiveWebAssembly`, the server prerender fails with HTTP 500, `InvalidOperationException: Cannot provide a value for property 'Env' on type 'EnvRepro.Client.Banners.WasmBanner'. There is no registered service of type '...IWebAssemblyHostEnvironment'`. `HostBanner.razor` tries the "shared" `IHostEnvironment` instead: it won't even compile in the client project until you add `Microsoft.Extensions.Hosting.Abstractions` (CS0234), and once it does, `/host-env` prerenders fine (HTTP 200, banner says "Development ... Static") but when WebAssembly starts, the browser logs `There is no registered service of type 'Microsoft.Extensions.Hosting.IHostEnvironment'` and the Blazor error bar appears. Run it with `ASPNETCORE_ENVIRONMENT=Development dotnet run --project EnvRepro --no-launch-profile --urls http://localhost:5871` from this folder (global.json pins SDK 10.0.102), then `curl -i localhost:5871/wasm-env` and `node tools/guide-shots/probes/environment-view.mjs` (BASE env var overrides the URL) for the browser side.
