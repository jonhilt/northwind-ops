# ssr-client-validation: .NET 10 repro

A static SSR Blazor app on .NET 10 (pinned by this folder's `global.json`) with the same `NewSupplierForm` model (`[Required, StringLength(40)] Company`, `[Required, EmailAddress, StringLength(60)] Email`) and the same `EditForm` + `DataAnnotationsValidator` + `Enhance` markup as the Field Guide demo. It shows the problem the guide entry describes: the rendered `<input>`s carry no rules at all (`<input id="email" name="Input.Email" class="valid" />`, no `data-val-*`, no `required`, no `<blazor-client-validation-data>`), so typing `sales@` and pressing Tab shows nothing and makes no request, and the error only appears after Save POSTs the form and the server re-renders the page (the server time and render counter move). Run it with `dotnet run --urls http://localhost:5440`, then either open the page and try it, POST an invalid form with curl (the 200 response contains `The Email field is not a valid e-mail address.`), or run `node probes/ssr-client-validation.mjs http://localhost:5440` from `tools/guide-shots` to print the input's attributes, the messages, the POST count and the server time after each step.
