# tempdata-ssr repro (.NET 10)

A minimal .NET 10 static-SSR Blazor app (pinned by `global.json` to SDK 10.0.102) showing the two hand-rolled ways to say "Order 11078 saved" after a POST-redirect-GET, since Blazor components had no TempData before .NET 11. `/orders/{id}` has two forms: one redirects to `/orders?saved={id}` (the flag stays in the URL, so a refresh shows "saved" again and anyone can open `/orders?saved=99999` and see "Order 99999 saved" without saving anything), the other sets a plain `Status` cookie with a 5-second MaxAge like the Identity template's `IdentityRedirectManager` (shows once, but a forged cookie renders whatever text the sender chose, and a redirect slower than 5 s loses the message). Run `dotnet run --urls http://localhost:5437` here, then `./probe.sh` in another terminal to drive both flows with curl and print the 302s, Set-Cookie headers and banners. `dotnet build -p:TryNet11Api=true` compiles `Probe/Net11Api.razor` and fails with CS0246 for `ITempData` and `SupplyParameterFromTempData`, confirming the API does not exist in .NET 10.
