# quickgrid-onrowclick: .NET 10 repro

An Interactive Server Blazor app on .NET 10 (pinned by this folder's `global.json`, QuickGrid 10.0.2) with three ticket rows and three pages. `/` is the guide's "button in every row" workaround: clicking the Subject or Customer cell leaves "Nothing open | Handler calls: 0" and the cursor stays `auto`; only the Open button opens the ticket. `/try-onrowclick` writes the .NET 11 markup (`<QuickGrid TGridItem="TicketRow" ... OnRowClick="Open">`) against .NET 10's QuickGrid: it builds with no warning or error, because QuickGrid captures unmatched attributes, and renders `onrowclick="Open"` as a dead HTML attribute on the `<table>`, so clicking a row does nothing, silently. `/div-in-cells` is the workaround posted on dotnet/aspnetcore#44899 (a clickable `<div>` in each `TemplateColumn`): clicking a cell's padding (the cell is 215x38, the div 167x18) does nothing, only the text area opens the ticket, and every `PropertyColumn` has to become a `TemplateColumn`. Run it with `ASPNETCORE_ENVIRONMENT=Development dotnet run --urls http://localhost:5391` (Development is needed so `_framework/blazor.web.js` is served from the build output; without it the script comes back empty and nothing is interactive), then from `tools/guide-shots` run `node probes/quickgrid-onrowclick.mjs http://localhost:5391` to print what each click did.
