# wasm-hosted-services repro (.NET 10)

A minimal standalone Blazor WebAssembly app (pinned by `global.json` to SDK 10.0.102) that registers the same `BackgroundService` three ways and shows each one's tick count on an Orders page and a Customers page: `HostedWatcher` is registered exactly as the guide's .NET 11 `Program.cs` does (`AddSingleton` + `AddHostedService(sp => ...)`), `ManualWatcher` is the .NET 10 workaround (a singleton started by hand with `StartAsync` before `RunAsync`), and the Orders page also owns its own `PeriodicTimer`. On .NET 10 the `AddHostedService` watcher stays at `started=False ticks=0` forever with no warning or error anywhere, the hand-started one keeps counting across pages, and the component timer restarts from 0 each time you come back to Orders. Note that a stock .NET 10 WebAssembly project cannot even see `BackgroundService`/`AddHostedService`: you have to add `Microsoft.Extensions.Hosting.Abstractions` yourself (build with `-p:NoHostingPackage=true` to get CS0234/CS0246); once you do, it compiles cleanly and is silently ignored. Run `dotnet run --urls http://localhost:5345` here, then `node probes/wasm-hosted-services.mjs` from `tools/guide-shots` to print the three counters at 5 s on Orders, after switching to Customers, and after switching back.
