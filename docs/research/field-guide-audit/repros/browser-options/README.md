# browser-options repro (.NET 10)

A minimal .NET 10 Blazor Web App (pinned by `global.json` to SDK 10.0.102) showing what setting reconnection options looked like before `BrowserOptions`: the only way in was `Blazor.start({ circuit: { reconnectionOptions: ... } })` in JavaScript, with `autostart="false"`. `Components/App.razor` picks a startup script from `?mode=`: `default` (no script, Blazor's defaults), `correct` (`maxRetries: 20, retryIntervalMilliseconds: 2000`), `typo` (`maxRetry` / `retryIntervalMs`, misspelt) and `config` (`@Config["Reconnect:Tries"]` pasted into the script, while `appsettings.json` only has `Reconnect:IntervalMs`). The home page has a server-interactive Pick button plus Blazor's `components-reconnect-current-attempt` / `components-reconnect-max-retries` spans. Run `ASPNETCORE_ENVIRONMENT=Development dotnet run --urls http://localhost:5197` here, then from `tools/guide-shots` run `node probes/browser-options.mjs`: for each mode it clicks Pick twice, closes the circuit's connection (`Blazor._internal.forceCloseConnection()`), makes every rejoin's `/_blazor/negotiate` fail, and samples the attempt counter and reconnect dialog once a second. Observed: `correct` counts "1 of 20, 2 of 20, 3 of 20..." with "trying again in 2 seconds"; `typo` is indistinguishable from `default` ("11 of 30" after one second, then "trying again in 5 seconds"), with no warning anywhere; `config` renders `maxRetries: ,`, the browser throws `SyntaxError: Unexpected token ','`, Blazor never starts, and the Pick button does nothing (stays at 0).
